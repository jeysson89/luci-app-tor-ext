# luci-app-tor-ext

Расширенное приложение LuCI для управления установленным **Tor** на OpenWrt 25.12 (rpcd/ucode, без CBI). Интерфейс на русском.

## Что входит

| Раздел | Для чего |
|--------|----------|
| **Статус** | Состояние Tor, bootstrap, версия, цепочки, выходной узел, график трафика с пиком, проверка внешнего IP через Tor |
| **Мосты** | Мосты по типам транспорта (obfs4, snowflake, meek_lite, webtunnel, обычный); кнопка «+» добавляет мост, «Проверить» запускает изолированную проверку только этого моста |
| **Конфигурация** | Редактор `/etc/tor/torrc`, проверка `tor --verify-config`, резервные копии (последние 20) и восстановление |
| **Порты и сервисы** | SOCKS / TransPort / DNSPort / ControlPort, скрытые сервисы `.onion` (добавление, адрес, удаление) |
| **Проксирование** | Клиенты (выбор из аренд DHCP или вручную), перенаправление DNS/TCP в Tor, Kill-switch, блокировка IPv6 / QUIC / DoT |
| **Трафик** | Соединения клиентов через Tor, фильтр по устройству, закрыть соединение / все соединения устройства |
| **Логи** | Журнал Tor, системный лог, лог приложения |
| **Мониторинг** | Сторожевой таймер (cron), Telegram / веб-хук уведомления |

## Быстрая установка

Просто запустите на роутере:

```sh
ssh -t root@192.168.1.1 \
  'wget -qO- https://raw.githubusercontent.com/jeysson89/luci-app-tor-ext/main/install.sh | sh'
```

Скрипт сам:
1. проверит систему и установит недостающее (`tor`, `curl`, `nftables`, `conntrack`, `luci-base`, `rpcd-mod-ucode`);
2. установит веб-интерфейс (готовый `.apk`);
3. выполнит базовую настройку `torrc`;
4. спросит, добавить ли свои мосты;
5. спросит, какие устройства (из аренд DHCP) перенаправлять через Tor.

После установки откройте в браузере:

```
http://192.168.1.1/cgi-bin/luci/admin/services/tor-ext/status
```

## Что дальше

- **Мосты** — в разделе «Мосты» нажмите «+ Добавить мост», укажите адрес/отпечаток/параметры, нажмите «Проверить» и «Сохранить».
- **Устройства через Tor** — в разделе «Проксирование» выберите устройство из аренд DHCP и нажмите «Применить».
- **Проверка** — `ubus call tor-ext status` и `ubus call tor-ext trafficGet`.

## Сборка (только если нужно пересобрать пакет)

Пакет `luci-app-tor-ext-1.0.0-r1.apk` уже собран и лежит в `dist/` и в релизах GitHub. Собирать вручную не нужно — достаточно `apk add --allow-untrusted` файла из вложения релиза.

Если хотите пересобрать, есть `Makefile` для OpenWrt SDK и `dev/build-apk.ps1` (статический `apk` Alpine).
